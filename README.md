# 沿海城市潮汐防洪推演系统（交互原型）

面向沿海城市防洪调度的多方案推演原型：同屏呈现**降雨、潮位、河道水位、泵站负荷、闸门状态**，
支持时间轴拖拽复盘积水形成与消退、运行中调整闸门开度/泵站组合/分洪顺序并**自动重新推演**，
对**倒灌、设备过载、上下游方案冲突**给出原因解释与**可执行替代组合**，支持**多方案同步回放对比**与
**意外断连后恢复未完成的推演**。

> 水动力部分为教学/演示用途的**概念模型**（节点水量平衡 + 孔流/泵站简化关系），
> 结构与参数均为虚构，不构成任何工程设计或调度依据。

## 运行

零依赖、纯原生 HTML/CSS/JS，无需构建：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：本地静态服务器
python3 -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000
```

## 功能清单

- **五要素同屏**：雨强柱、潮位/河道水位曲线、街区积水深度色块、泵站在线台数与负荷、各闸门开度与流向。
- **48 小时时间轴**：6 分钟步长（480 步），可拖拽、点击曲线/告警跳转，1×/4×/16×/60× 播放，键盘空格与方向键操作。
- **运行中调度调整**：
  - 挡潮闸 G0：手动固定开度，或“自动挡潮”（潮位≥内河自动落闸）；
  - 6 处自排闸：手动 / 防倒灌自动（街区水位≤河道自动关闭）；
  - 7 座泵站：逐站选择开机台数（0~3 台），高背压自动折减；
  - 2 处蓄滞洪区分洪闸：开度 + 进洪起止时刻（分洪顺序）。
  - 每次调整防抖触发全时段重算（约 20ms），**各街区峰值淹深与最早进水时间立即更新**。
- **告警诊断与替代组合**：
  - 倒灌（挡潮闸/自排闸/分洪渠）、泵站过载、蓄滞洪区漫溢；
  - 三类上下游冲突：高潮关闸顶托（C1）、河水高于地面仍自排（C2）、高水位强行进洪（C3）；
  - 每类告警给出“原因 → 动作”解释，并生成三套预设组合（御潮优先 / 主动分洪 / 低投入），
    每套都**重新推演并按淹深、淹没面积、倒灌量、漫溢、过载/冲突历时、能耗综合打分排序**，一键应用为新方案。
- **多方案比较**：任意方案“加入对比”后地图三屏/多屏同屏、时间轴同步回放，右侧表格逐项标绿最优。
- **断点续演**：方案、情景、时间轴位置每 15 秒及变更时自动写入 `localStorage`；
  刷新/崩溃后弹窗选择“恢复推演/放弃重来”。顶栏“模拟断连”可直接体验；另支持 JSON 导入/导出。
- **两套情景**：风暴潮叠加暴雨（高风险）、常规大潮强降雨。

## 模型说明（简化关系）

- 降雨：两场高斯雨峰 × 各街区分区系数，径流系数 0.85 直接进入街区当量库容；
- 潮位：M2 分潮（周期 12.42h）+ 风暴潮增水高斯峰；
- 闸/渠过流：`q = 开度 × qMax × √(上下游水位差)`，按“两节点水位拉平”上限做保正限流；
- 泵站：按街区积深估算来水需求，与装机能力比较得到负荷率，河道高水位时按背压折减；
- 每个 6 分钟步长内做 6 个子步积分并进行 6 小时中性热启动，避免初值与数值振荡伪影。
